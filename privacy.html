Daylog プライバシーポリシー

Daylog は、作成者本人だけが使う個人用の生活記録アプリです。

扱う情報

  • Google アカウントのメールアドレス（ログインのため）
  • Google カレンダーの予定（今日の流れの表示と、Daylog から予定を追加・変更・削除するため）
  • アプリに書いた日記・タスク・メモ・目標、PC の操作時刻とゲーム時間

使い方と保管

これらの情報は、本人の画面に表示するためだけに使います。データは Supabase のデータベースに保存し、本人のアカウントだけが読み書きできるよう設定しています。第三者への提供・販売・広告への利用はしません。

Google ユーザーデータ

Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

削除

アカウントを削除すると、保存したデータもすべて削除されます。Google の許可は Google アカウントの設定 からいつでも取り消せます。
